# Module 2: Hands-on Lab

## Lab: Exploring My Linux System

I used the terminal to identify my Linux distribution, check the kernel, and view basic system information.

### Commands Practiced

```bash
cat /etc/os-release
uname -r
hostnamectl
```

### What I Learned

* `cat /etc/os-release` showed that my system runs **Ubuntu 24.04.3 LTS**.
* `uname -r` showed my running kernel: **6.17.0-14-generic**.
* `hostnamectl` displayed general information about my system and hardware.

### Lab Takeaway

This lab helped me understand the difference between a **Linux distribution** and the **Linux kernel** and practice checking system information directly from the terminal.
