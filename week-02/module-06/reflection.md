

Module 6 changed how I approach Linux commands. Instead of memorizing every command and option, I learned that Linux already offers several ways to find help.

I practiced understanding the difference between `man`, `info`, and `--help`. I also learned how `type`, `which`, `whereis`, `whatis`, and `locate` can help me find commands, files, and documentation.

One useful thing I learned was how Info documentation is organized into connected sections. This makes it possible to explore a topic instead of only looking up one command.

### Key Takeaway

My biggest takeaway is that **being able to find the right documentation is an important Linux skill**. When I don't know a command or option, I can investigate it instead of guessing or relying on memorization.
