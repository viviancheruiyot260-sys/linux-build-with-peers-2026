


This module changed how I understand the term **open source**.

I learned that open source is not simply about getting software for free. It is about having access to the source code and having certain freedoms to study, modify, and share it.

I also learned why licenses are important. Different licenses give users different permissions, so I should always check the license before using or redistributing someone else's work.

The comparison between **GPL, MIT, BSD, and Creative Commons** helped me see that open-source and creative works can have different licensing rules.

### What I learned

My main takeaway is that **open source encourages collaboration, but the license sets the boundaries for that collaboration.**
