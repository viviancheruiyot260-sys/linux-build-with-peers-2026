Reflection

Module 11 introduced me to **Bash scripting** and how it can be used to automate tasks in Linux.

I learned how to create and edit shell scripts using `nano`, use **variables** to store information, use **conditionals** to make decisions, and use **loops** to repeat tasks.

At first, scripting felt difficult because there were many new concepts. However, practicing simple examples helped me understand how the different parts work together.
