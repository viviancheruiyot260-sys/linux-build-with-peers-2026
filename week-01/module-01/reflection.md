
# Module 1: Learning Reflection

This module gave me a clearer picture of what Linux actually is.

The concept I had to spend the most time understanding was the **kernel**. I initially thought of it almost like an API, but I now understand that the kernel is the core component that manages communication between software, hardware, and system resources.

I also learned the difference between **Linux, Ubuntu, GNU, and Linux distributions**, which I had previously treated almost as the same thing.

The GUI vs CLI section also connected with my interest in **Cloud and DevOps**, because I can now see why being comfortable with the terminal is important when working with Linux servers.

**Main takeaway:** I don't just want to memorize Linux commands. I want to understand what is happening underneath them.
