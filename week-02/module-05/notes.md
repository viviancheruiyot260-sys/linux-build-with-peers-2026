# Module 5: The Linux Command Line

## Key Concepts

* **Command Line:** Allows users to manage Linux by typing commands in the terminal.
* **Shell:** Interprets commands and tells the operating system what to do. **Bash** is a common Linux shell.
* **Command Structure:** `command [options] [arguments]`

  * Command = action
  * Option = how
  * Argument = target
* **History:** `history`, `↑`, `!!` help view and repeat previous commands.
* **Variables:** Store information, e.g. `name=Vivian`.
* **Environment Variables:** Provide information used by the shell and programs, such as `$HOME` and `$PATH`.
* **PATH:** Tells Bash where to look for executable commands.
* **Command Types:** Built-in commands, external commands, aliases, and functions.
* **Quoting:** `' '` and `" "` control how Bash interprets text. `$(command)` allows command substitution.
* **Control Statements:**

   `;` → run commands one after another
   `&&` → run the next command only if the first succeeds
  `||` → run the next command if the first fails
