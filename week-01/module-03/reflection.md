
# Module 3 Reflection — Working in Linux

This module helped me understand how Linux is used beyond just typing commands in the terminal. I learned the difference between the GUI and CLI and why the terminal is especially important when working with Linux servers.

I also understood the role of the kernel, processes, applications, and package managers. The section on security reminded me that Linux administration is not only about running commands but also about controlling access, keeping systems updated, and protecting users.
