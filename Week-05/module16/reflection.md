Reflection

In this module, I learned how Linux manages users and groups to control access to a system. I practised creating groups with `groupadd`, modifying them with `groupmod`, and creating user accounts with `useradd`.

I also learned how to add users to secondary groups using `usermod`, check account information with `getent`, and remove accounts using `userdel`. One important lesson was understanding the difference between primary and secondary groups and why account management should be handled carefully.

This lab helped me understand how Linux administrators manage users, groups, and access permissions. I am becoming more comfortable working with Linux commands and learning how they are used in real system administration.

**Key takeaway:** Managing Linux users and groups is not just about creating accounts; it is also about controlling access and keeping the system organized and secure.
