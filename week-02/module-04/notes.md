
# Module 4: Open Source Software and Licensing

## 1. Open Source Software

Open source software is software whose **source code is available** for people to view, study, modify, and share according to its license.

**Example:** Linux.

### Open vs Closed Source

* **Open source:** Code is available.
* **Closed source:** Code is kept private.

---

## 2. Software Licensing

A license explains what people are allowed to do with software, such as:

* Use it
* Modify it
* Share it
* Redistribute it

A software being **free** does not always mean it costs nothing. It can also mean freedom to use and modify it.

---

## 3. GNU GPL

The **GNU General Public License (GPL)** is one of the licenses used by Linux.

It allows people to use and modify the software. **Copyleft** also requires distributed modified versions to keep the same freedoms under the license.

---

## 4. FSF and OSI

**Free Software Foundation (FSF)** promotes software freedom and maintains licenses such as GPL.

**Open Source Initiative (OSI)** promotes open-source principles and approves licenses such as MIT and BSD.

---

## 5. Creative Commons

Creative Commons licenses are mainly used for **creative work** such as images, writing, music, and designs.

They can specify whether people can modify, share, or use the work commercially.

---

## 6. Open Source and Business

Open source does not mean businesses cannot make money.

Companies can earn through:

* Support
* Consulting
* Cloud services
* Training
* Enterprise products
