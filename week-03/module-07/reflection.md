
 Reflection

This module helped me understand how Linux organizes and navigates its filesystem.

I practiced using `pwd`, `ls`, and `cd` to locate myself, explore directories, and move around the filesystem. I also learned the difference between absolute and relative paths, as well as how to view hidden files and file details using `ls` options.

My biggest takeaway is that understanding the filesystem makes the terminal much easier to work with. Instead of guessing where files are, I can now confidently locate, navigate, and inspect them.
