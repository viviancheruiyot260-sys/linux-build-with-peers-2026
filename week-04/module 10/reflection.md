
 Reflection

Module 10 helped me understand how Linux can be used to work with text directly from the command line.

At first, commands like `grep`, `cut`, `sort`, and `wc` seemed like many commands to remember. After practicing them, I started to understand what each one is actually used for. For example, `grep` helps me search for specific text, while `cut` allows me to extract the part of the text I need.

I also learned how pipes (`|`) can connect commands together. This showed me that Linux commands do not always have to be used separately; they can work together to complete a task.

The biggest lesson for me was that text processing is useful for handling information quickly, especially when working with large files and system logs.

I am still learning the different options and regular expressions, but the hands-on practice made the concepts easier to understand.
