
# Module 2: Learning Reflection

Module 2 helped me understand operating systems in a way that connected more with what I already use every day.

Before this module, I knew that I was using Ubuntu, but I did not clearly understand the difference between **Linux, the Linux kernel, and a Linux distribution**. Learning this helped me understand that Ubuntu is a distribution built around the Linux kernel.

I also learned that choosing an operating system is not simply about asking which one is the best. It depends on what the computer will be used for, the required software, stability, compatibility, cost, and how the system will be managed.

The part I found most useful was learning about the **CLI and GUI**. I have used the terminal before, but this module helped me understand why the command line is so important when working with Linux servers, cloud computing, and DevOps.

I also did some hands-on practice on my Ubuntu system. I used `cat /etc/os-release` to identify my distribution, `uname -r` to check the kernel, and `hostnamectl` to view system information. Seeing the information directly from my own computer made the concepts easier to understand.

### Key Takeaway

The biggest lesson for me is that I don't want to just memorize Linux commands. I want to understand **what the command is doing and why I am using it**.

This module also made me more interested in learning Linux because I can already see how it connects to my growing interest in **Cloud and DevOps**.
