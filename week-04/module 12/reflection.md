Computer Hardware 

In this module, I learned about the main hardware components of a computer and how they work together. I now understand the roles of the CPU, RAM, motherboard, storage devices, graphics hardware, and power supply.

I also learned the difference between HDDs and SSDs, how partitions organize storage, and how device drivers help Linux communicate with hardware. I explored useful Linux commands such as `lscpu`, `free -h`, `lsblk`, `lspci`, and `lsusb` for checking hardware information.

One important lesson I learned is that understanding hardware makes troubleshooting easier. I also realized the importance of safely managing storage devices, checking hardware compatibility, and using a reliable power supply.
