# Module 1: Introduction to Linux

## 1. History of Linux

Linux has its roots in **Unix**, developed at Bell Labs in the 1970s.

In 1983, **Richard Stallman** started the GNU Project to create a free and open-source Unix-like operating system. GNU developed many important tools but did not have a complete kernel.

In 1991, **Linus Torvalds** created the Linux kernel. The Linux kernel was later combined with GNU tools and other software to create complete Linux-based operating systems.

**Simple timeline:**

```text
Unix → GNU Project → Linux Kernel → Linux Distributions
```

## 2. The Linux Kernel

The **kernel** is the core part of an operating system. It manages communication between software and hardware and manages system resources such as:

* CPU
* Memory
* Processes
* Storage
* Hardware devices
* Networking

```text
Applications
     ↓
System calls
     ↓
Linux Kernel
     ↓
Hardware
```

Linux technically refers to the **Linux kernel**, although "Linux" is commonly used to describe complete Linux-based operating systems.

## 3. GNU

**GNU** stands for **GNU's Not Unix**.

The GNU Project was started by Richard Stallman in 1983. It created many important tools used in Linux-based systems, including Bash, GNU Core Utilities, and GCC.

GNU tools and the Linux kernel work together with other software to form complete Linux-based systems.

## 4. Is Linux Open Source?

Yes. The **Linux kernel is open source** and is licensed under the **GNU General Public License (GPL)**.

Open source means the source code is available under a license that allows people to use, study, modify, and redistribute the software according to its terms.

## 5. Linux Distributions

A **Linux distribution (distro)** is a complete operating system built around the Linux kernel.

It can include:

* Linux kernel
* GNU tools
* System libraries
* Package manager
* Desktop environment
* Applications

Examples include:

* Ubuntu
* Debian
* Fedora
* Arch Linux
* Red Hat Enterprise Linux

**Important:** Ubuntu is a Linux distribution, not the Linux kernel.

## 6. GUI and CLI

Linux supports both graphical and command-line interaction.

### GUI — Graphical User Interface

Uses windows, icons, menus, and buttons.

### CLI — Command-Line Interface

Allows users to interact with the system by typing commands into a terminal.

Examples:

```bash
pwd
ls
cd
```

CLI is especially useful for managing Linux servers, automation, cloud computing, and DevOps.

## Key Takeaways

* Linux is technically the Linux kernel.
* The kernel manages hardware and system resources.
* GNU created many important tools used with Linux.
* Linux is open source.
* Ubuntu is a Linux distribution.
* Linux can be accessed through both GUI and CLI.
