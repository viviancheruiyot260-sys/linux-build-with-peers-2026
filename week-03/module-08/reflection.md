Reflection

This module helped me understand how Linux handles files and directories from the command line.

I learned that globbing allows me to work with multiple filenames using patterns such as `*`, `?`, `[ ]`, and `[! ]`. I also learned that the shell expands these patterns before the command runs.

I practiced using `cp` to copy files, `mv` to move and rename them, `touch` to create empty files, and `rm` and `rmdir` to remove files and directories. I also learned how options such as `-i`, `-n`, `-v`, and `-r` change how these commands behave.

The biggest lesson for me was to be careful with commands that can overwrite or permanently delete data. Using options like `-i` and `-n` can help prevent accidental changes.
