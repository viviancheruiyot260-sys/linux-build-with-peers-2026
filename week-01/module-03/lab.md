Working in Linux

Objective

Practice basic Linux commands related to system information, processes, packages, networking, and security.

## Commands Practiced

```bash
uname -a
lsb_release -a
ps
ps aux
sudo apt update
nano linux-notes.txt
cat linux-notes.txt
ip addr
sudo ufw status
```

## What I Practiced

* Checked my Linux system and Ubuntu version.
* Viewed running processes.
* Updated the package list using `apt`.
* Created and edited a text file using `nano`.
* Checked network information.
* Checked the firewall status.
