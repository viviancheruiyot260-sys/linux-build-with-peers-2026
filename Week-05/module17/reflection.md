Module 17: Reflection — File Ownership and Permissions

In this lab, I learned how Linux manages file ownership and permissions. I practised using `ls -l` and `stat` to inspect files and understand the permissions assigned to their owners, groups, and other users.

I also learned how to modify permissions using symbolic notation with `chmod` and numeric notation such as `775`. Creating and executing a shell script helped me understand why execute permission is necessary when running a file directly.

Finally, I explored how `chown` and `chgrp` change file ownership and how the recursive option `-R` applies group ownership changes to directories and their contents.

**My key takeaway:** Understanding Linux file permissions is essential for controlling access, protecting files, and managing a system securely. I now have a better foundation for working with ownership and permissions from the terminal.
