Computer Hardware Labs

## Lab 1: Viewing CPU Information
**Command:**
```bash
head -n 20 /proc/cpuinfo
```
Displays the first 20 lines of CPU information, including the processor model, speed, and supported features.

## Lab 2: Viewing Kernel Modules
**Command:**
```bash
lsmod
```
Lists currently loaded Linux kernel modules, their memory usage, and module dependencies.

## Lab 3: Identifying Disk Devices
**Command:**
```bash
sudo fdisk -l
```
Lists storage devices and their partitions. Avoid modifying partitions during this inspection because incorrect changes can cause data loss.
