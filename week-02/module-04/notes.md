
# Module 4: Open Source Software and Licensing

## 1. Open Source Software

Open source software makes its **source code available** so people can study, modify, and share it according to its license.

Unlike closed-source software, the code can be inspected and improved by a community.

## 2. Software Licensing

A software license explains what users are allowed to do with software.

It can define whether we can:

* Use the software
* Modify the code
* Share it
* Redistribute it
* Use it commercially

## 3. GPL and Copyleft

Linux uses the **GNU General Public License (GPL)**.

The GPL allows people to use and modify the software. **Copyleft** means that when modified versions are distributed, they generally need to keep the same licensing freedoms.

## 4. FSF and OSI

The **Free Software Foundation (FSF)** promotes software freedom and supports licenses such as the GPL.

The **Open Source Initiative (OSI)** promotes open-source principles and maintains a list of approved open-source licenses such as MIT and BSD.

## 5. Creative Commons

Creative Commons licenses are mainly used for **creative works**, including:

* Images
* Writing
* Music
* Designs

Different licenses can require credit, prevent commercial use, or restrict modifications.

## 6. Open Source Business Models

Open source software can still be used to build businesses.

Companies can make money through:

* Technical support
* Consulting
* Cloud services
* Training
* Enterprise products
* Hardware
